# VICECITYWIRE — Native app preparation

The public GitHub Pages site remains the live PWA. The Capacitor setup in this repository prepares a separate, locally bundled Android/iOS app from the same HTML, CSS, JavaScript and asset files.

## Requirements

- Node.js 22 or newer
- Android Studio and Android SDK for Android builds
- Xcode on macOS for iOS builds

## First-time setup

```bash
npm install
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

Build the web bundle again after website changes, then sync:

```bash
npm run cap:sync
```

The web bundle is copied to `www/`. The native Android project is generated by Capacitor in `android/` and is intentionally not committed yet.

## App identity

- Display name: VICECITYWIRE
- Android application ID: `com.industryai.vicecitywire`

The application ID should be treated as permanent once the app is published.

## Important release work still required

- Create and test a signed Android App Bundle (AAB).
- Add final store graphics, screenshots and listing text.
- Publish a public privacy policy and link it inside the app.
- Complete Google Play Data safety and content declarations.
- Verify all game artwork, trademarks and third-party map usage rights.
- Test on physical Android devices and review offline behavior.

Do not upload a release build until the privacy, rights and Play Console checks are complete.
